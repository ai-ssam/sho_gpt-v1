# Shoulder ROM Lab v5.2.0

## v5.2 추가 구현 (2026-10-04)

- 별도 관리자 화면 및 카메라 장치·해상도·FPS·반전 설정 이동.
- 카메라 스틸컷 / 업로드 영상 프레임으로 중립자세 등록, 좌표 수정, 새 버전 저장·선택.
- 시작 전·복귀 후 중립 유지시간을 각각 설정하고 자동촬영에 적용. 사용한 설정·기준 이미지를 촬영 결과에 보존.
- 3단계 결과 문구·경계값 설정. 제한 적음(초록), 경도(노랑), 중증도(빨강)를 크게 표시. 기본 경계 20·50은 임상 미검증 시험값.
- 업로드 카드 클릭 시 파일 선택, 썸네일·파일정보는 카드 하단 별도 영역.
- 신규 BIR 분석은 손목만 사용. 엄지 대체 및 BIR 손 모델 추론 제거.

기존 소스 폴더는 변경하지 않고 `shoulder-rom-lab-v5.2`에서 개발합니다. 실행 주소는 **http://localhost:4174/** 입니다. 4173의 기존 버전과 별도 실행됩니다. 포트가 달라 브라우저 저장 데이터도 별도이므로 기존 기록은 자동으로 나타나지 않습니다.

FE2 통합·양 극점 편집, BIR 손목 t구간, IRER 개인 길이 보정·보조 추정, 활성 동작 관리, 기본 팔·분석 간격, 설정 JSON 백업을 추가했습니다. 실제 카메라·임상 측정 정확도는 검증 전입니다. 알고리즘과 시험값은 [알고리즘 설명](docs/algorithms-v5.2.md)을 참고하세요.

자세한 변경·검증 기록: [v5.2 작업 기록](docs/v5.2-release.md).

한쪽 팔의 AB(외전), FE2(신전–굴곡 통합), BIR(등 뒤 손 올리기), IRER(외회전)을 촬영하거나 업로드하여 분석하는 로컬 웹 앱입니다. FE·ER·CIR은 기본 숨김이며 관리자에서 활성화할 수 있습니다.

## 실행

Node.js 22 이상에서 프로젝트 폴더를 열고:

```sh
npm ci
npm run dev
```

Chrome 또는 Edge로 http://localhost:4174 에 접속합니다. Windows에서는 start-local.bat도 사용할 수 있습니다. package.json과 앱 버전은 v5.2.0입니다.

## v5 사용 흐름

1. 홈에서 카메라 촬영 또는 영상 업로드를 선택합니다.
2. 환자정보와 측정할 한쪽 팔을 설정합니다.
3. 동작당 1회 수행한 영상을 등록합니다. 재촬영·재등록은 해당 동작을 교체합니다.
4. 다음 동작 준비 중 이전 영상이 Worker에서 순차 분석됩니다.
5. 활성 동작 등록 후 최종 결과를 엽니다. 미완료·무효 동작은 점수 평가를 보류합니다.
6. 상세보기에서 분석 프레임 앞뒤 이동, 관절점 수정, 대표 프레임 선택, 필요한 구간 정밀 재분석을 수행합니다.
7. 수정 내용을 적용하고 **결과 + 원본 저장**을 누릅니다.

## 촬영

장치·해상도·FPS·카운트다운·미리보기 반전을 설정합니다. 중심선·수평선·촬영 영역·자세 안내를 선택할 수 있습니다. 음성 또는 신호음으로 카운트다운과 시작·종료를 알립니다.

자동 촬영은 시험 기능입니다. 시작자세 1.5초 유지 → 카운트다운 → 동작 수행 확인 → 시작자세 복귀 1.2초 유지 순으로 동작합니다. 촬영은 최대 2분이며 수동 종료가 가능합니다. IRER은 팔꿈치를 몸통 옆에 붙이고 90° 굽힌 정면 자세입니다. 다른 동작은 팔을 몸 옆으로 내린 자세에서 시작·복귀합니다. 동작량이 작거나 관절이 가려져 자동 종료되지 않으면 수동 중지를 사용합니다.

카메라 권한은 연결 버튼을 눌렀을 때 요청합니다. 마이크는 녹음하지 않습니다. 실제 카메라와 자세 감지 정확도는 실기기 검증이 필요합니다.

## 구간과 관절점 편집

- 시작·종료 시각으로 분석구간을 지정합니다. 구간 적용·재분석은 기존 수동 보정을 초기화한다는 확인 후 실행합니다.
- 상세보기의 정밀 재분석은 선택 구간을 매 프레임 분석하고 기존 수동 좌표를 보존합니다.
- 기본 분석 간격은 3프레임이며 변경할 수 있습니다. −1/+1은 분석 프레임 이동입니다. 원본 연속 프레임 탐색이 필요하면 해당 구간을 정밀 재분석합니다.
- 자동·수동·최종 대표 프레임을 구분하고 자동값 복원이 가능합니다.
- BIR의 도달 높이와 최소 팔꿈치각은 별도 프레임입니다.
- IRER은 몸통 기준 3D 외회전 추정입니다. 2D 드래그는 화면 좌표만 수정합니다. 외회전 재계산에는 상세보기의 3D 관절점 편집을 사용합니다. 자세와 추정값을 확인해야 점수에 반영됩니다.
- CIR은 새 검사에서 숨겼습니다. 이전 JSON의 CIR 결과는 보존하여 다시 내보낼 수 있습니다.

## 결과와 원본 저장

촬영 직후에는 원본을 메모리에 보관합니다. **결과 + 원본 저장**은 현재 브라우저의 IndexedDB에 두 데이터를 한 트랜잭션으로 저장합니다. 저장 실패 시 성공으로 표시하지 않습니다. 검사별 ID로 저장하므로 같은 환자의 여러 검사를 보존합니다. 같은 검사를 다시 저장하면 해당 검사를 갱신합니다. 브라우저/OS의 메모리 페이징까지 금지하는 것은 아닙니다.

**결과 + 원본 ZIP**은 result.json과 videos 폴더를 PC 파일로 내보냅니다. 압축을 풀면 원본을 재생할 수 있습니다. ZIP 자체를 앱으로 가져오는 기능은 없습니다. 복원은 result.json을 JSON 복원한 뒤 각 원본 영상을 다시 연결합니다. 저장된 브라우저 기록을 불러오면 원본도 자동 복원됩니다.

JSON 단독 내보내기는 결과·좌표·대표 이미지·평가 기준을 포함하고 원본 바이너리는 포함하지 않습니다. 브라우저 데이터 삭제 시 로컬 저장 기록도 사라지므로 ZIP 백업을 이용하세요. 환자정보가 포함되므로 보관 위치를 관리하세요. 영상은 외부 서버로 전송하지 않습니다.

## 동작 의심도점수와 관리자 설정

관리자 설정은 기본·동작, 카메라, 중립자세, 평가기준, 백업·복원 가로탭으로 분리합니다. 활성 동작, 가중치와 각도 경계값, BIR 분할 수·t 경계값을 편집하고 CSV로 가져오기·내보내기 할 수 있습니다. 가중치 합계 100과 구간 순서를 검증합니다. 기본값·동작 설정 저장은 현재 검사에도 기준을 적용·재계산하며 이전 기준 이력을 보존합니다. 분석 프레임 간격은 모든 동작의 다음 분석·재분석에 반영됩니다. 저장된 과거 검사는 덮어쓰지 않습니다. 중립자세까지 포함한 JSON 설정 백업도 제공합니다.

명칭은 **동작 의심도점수**, 단위는 0~100점입니다. 임상 미검증 샘플 기준이며 질환 확률이 아닙니다. 유효 측정 부족·IRER 추정 미확인·미완료 동작이 있으면 종합점수는 평가 보류입니다. 각 저장 결과에 적용 기준 스냅샷을 포함합니다. 이전 척추 수준 BIR 기준은 이전 검사 호환용으로만 유지합니다.

## 성능과 검증

GPU 모델 초기화를 우선 시도하고 실패하면 CPU로 전환합니다. Worker와 모델 재사용을 이용하고, 손 모델은 CIR에만 실행합니다. 자동 촬영 자세 감지 입력은 최대 480px, 정밀 분석 입력은 데스크톱 최대 1280px입니다. UI에서 처리시간·사용 delegate·분석 프레임 수를 확인할 수 있습니다. 무제한 병렬 처리는 메모리 부족을 유발하므로 영상 분석은 큐에서 순차 처리합니다.

```sh
npm test
```

자동 테스트는 계산·대기열·DOM 흐름·모의 카메라·저장/원본 복원·ZIP·자동촬영 상태 전이를 검사합니다. 샘플 영상과 FFmpeg가 없는 환경에서는 관련 2개 검사를 건너뜁니다.

실제 환자 영상의 IRER 각도 정확도, GPU 성능 향상, 실제 카메라 자동 촬영, iOS 종단간 흐름은 아직 실측 검증하지 않았습니다. 로컬 코드 업데이트이며 운영 사이트 배포와 GitHub 업로드는 이 작업에서 수행하지 않았습니다.
