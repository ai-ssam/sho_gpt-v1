# Shoulder ROM Lab 차기 버전 기획

정리일: 2026-10-02. 상태: 기획 확정사항 기록, 앱 구현 전. 앱 버전 번호는 미정.

## 사용자 확정사항

| 항목 | 결정 |
|---|---|
| 검사 대상 | 검사별 한쪽 팔. 시작 시 좌/우 선택 |
| 수행 횟수 | 동작당 1회 후 재촬영 선택 |
| 상세 편집 | 분석 프레임 우선, 필요 구간 정밀 재분석. 앞뒤 프레임 이동 및 대표 프레임 선택 |
| 최종 저장 | 분석 결과와 원본 영상 모두 저장 |
| 설정 관리 | PC에서 설정. 표 편집과 CSV 가져오기·내보내기 |
| 결과 명칭 | 동작 의심도점수, 0~100점. 질환 확률이 아님 |

## 검사 동작

- AB 외전, FE 굴곡, ER 신전, BIR 등 뒤 손 올리기, IRER 외회전.
- CIR은 신규 검사 화면에서 숨겨 보류하고 기존 결과는 보존한다. IRER로 자동 변환하지 않는다.
- IRER: 정면 촬영, 위팔을 몸통 옆에 붙이고 팔꿈치를 90° 굽힌 상태에서 전완을 바깥쪽으로 외회전한 뒤 시작자세로 복귀한다. 내회전과 근력은 현재 측정 범위에 포함하지 않는다.
- BIR: 최대 도달 높이와 최소 팔꿈치각을 서로 다른 프레임으로 보존한다.

## 화면과 이동

홈 → 환자·측정팔 설정 → 카메라/업로드 선택 → 촬영·등록 및 분석 대기 → 최종 결과 → 상세 수정·저장.

- 모드 선택은 초기 화면이나 상단에 명확히 배치한다.
- 카메라 모드는 미리보기·촬영 안내 중심, 업로드 모드는 파일 등록·구간 확인 중심으로 대기 화면을 구성한다.
- 다음 동작 준비 중 앞선 영상은 분석한다. 진행·실패·재시도를 동작별로 표시한다.
- 최종 결과는 별도 화면으로 구성하고 출력용 보기를 제공한다.
- 홈과 이전 단계 이동을 일관되게 제공하고 작업 내용을 유지한다. 미저장 데이터를 잃는 이동에는 안내한다.

## 카메라와 자동 촬영

- 장치·해상도·FPS·좌우 반전 초기설정.
- 중심선·수평선·촬영 영역·시작자세 안내·스켈레톤 등 필요한 표시를 선택박스로 제어한다. 안내선은 원본 영상과 분리한다.
- 음성 또는 신호음 카운트다운과 시작·종료 안내. 화면 안내도 함께 제공한다.
- 자동 촬영: 시작자세 안정 유지 → 카운트다운 → 촬영 → 실제 동작 수행 확인 → 시작자세 복귀 및 안정 유지 → 종료.
- 수동 시작·종료와 강제 종료를 제공한다. 자세 감지 실패 시 수동 촬영으로 진행할 수 있어야 한다.
- 한 동작을 1회 수행한 뒤 영상 확인 및 재촬영 선택을 제공한다.

## 구간 및 프레임 편집

- 촬영·업로드 영상에서 시작·종료 분석구간을 수동 지정한다. 원본은 보존하고 구간 정보만 별도로 관리한다.
- 상세보기는 분석한 프레임을 우선 제공하며 앞뒤 이동·시간·원본 프레임 번호를 표시한다.
- 필요한 구간은 정밀 재분석하여 프레임을 추가 탐색하고 대표 프레임을 선택한다.
- 원본 프레임 이동과 분석 프레임 이동은 구분한다. 미분석 프레임에는 분석된 관절점이 있는 것처럼 표시하지 않는다.
- 관절점 수정·적용·취소·자동값 복원 및 재계산을 제공한다.
- 자동·수동·최종 대표 프레임과 좌표를 보존한다. 영상 배경·좌표·시각·계산값을 같은 프레임에 맞춘다.

## 메모리와 저장

- 촬영 직후 영상은 우선 메모리에 보관해 분석하고, 사용자가 최종 저장할 때 결과와 원본 영상을 모두 저장한다.
- 저장 대상은 검사 결과, 자동·수정·최종 좌표, 대표 이미지, 분석구간, 적용 평가 설정, 해당 결과에 사용한 원본 영상이다.
- 결과와 영상은 검사 ID·동작·촬영 회차 등으로 연결하여 다시 열었을 때 영상과 좌표를 복원한다.
- 결과만 저장되고 영상이 실패한 경우 전체 저장 성공으로 표시하지 않는다. 실패 항목 재저장을 제공한다.
- 저장 전 재촬영으로 대체된 영상의 보관 정책과 실제 저장 형식·위치는 상세 설계에서 정한다.

## 성능

- GPU 추론, Worker, 모델 재사용, 영상 복사 최소화, 메모리 회수를 검토한다.
- 촬영 중 가벼운 자세 감지와 촬영 후 정밀 분석을 구분한다.
- 기기별 실측에 따라 처리 해상도·프레임 밀도·동시 작업 수를 결정한다.
- 프레임 이미지 전체를 메모리에 쌓기보다 필요한 프레임을 생성하는 방향으로 설계한다.

## 평가와 PC 설정

- 결과 명칭은 동작 의심도점수이다. 수치 단위는 /100점으로 한다.
- 기준 자료: [설명 문서](evaluation/sample-evaluation-v0.1.md), [JSON](evaluation/sample-evaluation-v0.1.json), [CSV](evaluation/sample-evaluation-v0.1.csv).
- 현재 경계값·가중치·단계명은 임상 미검증 샘플이며, 새 명칭 결정만으로 검증된 기준이 되지 않는다.
- PC 설정 화면에서 동작별 가중치·경계값을 표로 수정하고 CSV로 교환한다. 별도 서버 관리자 페이지는 현재 범위에 포함하지 않는다.
- 필수 동작 누락·측정 불량은 평가 보류로 처리한다. 분석 품질을 점수와 별도로 표시한다.
- 결과별 기준 버전과 스냅샷을 저장하고 설정 변경 시 과거 결과를 자동 덮어쓰지 않는다.

## 구현 전 검증·설계 항목

- IRER 외회전각의 측정 방법 및 각도계 대비 정확도. 2D 팔꿈치각을 외회전각으로 사용하지 않는다.
- 동작별 시작자세 허용오차, 자동촬영 안정 유지시간, 최소 동작량, 검출 누락·최대 촬영시간 처리.
- 정밀 재분석의 프레임 밀도와 수정 좌표 보존·충돌 처리.
- 결과·원본 영상 동시 저장 형식, 폴더 선택 및 재열기 방식, 재촬영 원본 보관 정책.
- 단계별 UI 명칭과 샘플 평가 기준의 검증.

이 문서는 사용자 확정사항과 후속 설계 항목을 기록한 것이다. 현재 앱의 동작·저장·채점 기능은 변경하지 않았다.
