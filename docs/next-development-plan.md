갱신일: 2026-10-13. 기준 보관본: v5.4 irer2D (e477ef5).
상태: 사용자가 '한눈에 요약'을 선택하여 v5.5-dev에 아래 계산 모드/결과 카드 구현. v5.4 보관본의 앱 코드는 변경하지 않는다. 개발본 실행 포트는 4176.

검증 결과: 자동 테스트 55개 통과·2개 건너뜀. 초기 화면·관리자 선택/저장 브라우저 확인. 검사 JSON 파일 선택 중 브라우저 연결 만료 및 복구 시간 초과로 실제 브라우저 결과 카드·상세 비교·반응형/출력 시각 검증은 미완료. DOM 통합 흐름은 통과. 실측 정확도 검증과는 별개다.

## IRER 계산 방식 선택

관리자 설정 → 동작·평가기준 → IRER 계산 방식:

- 2D 길이비 (기본): irer-2d-asin-v1. 현재 반대팔 전완 참조/개인 보정 정책 유지.
- 3D 관절좌표 추정 (기존): 전환 전 4d3605d의 계산/제외 조건을 보존. 90° 부근 앞쪽 성분 탈락 조건도 그대로 명시한다. 개선하면 별도 알고리즘 ID를 부여한다.
- 비교 모드 (검증용): 같은 분석 프레임의 2D/3D 값·차이·성공/실패 사유를 나란히 제공한다. 각 방법의 최대각/대표프레임 비교는 동일 프레임 비교와 분리한다.
- 비교 모드 주 계산 선택: 2D 또는 기존 3D. 기본 2D. 점수·최종 대표프레임은 주 계산을 따르며 평균하지 않는다.

## 적용과 데이터 정책

- 관리자 기본값과 검사별 계산 방식 스냅샷을 구분하고 알고리즘 ID/버전, 주 계산 방식, 보정/품질 정보를 저장한다.
- 변경 시 현재 검사에 적용·재계산하는 명시적 동작을 제공한다. 이전 방식·결과 이력을 보존하고 확인 상태를 초기화한다. 과거 저장 검사를 자동 변경하지 않는다.
- 비교/3D에는 world 좌표가 필요하다. 2D-only 기록에 없으면 원본 영상 재분석 필요로 표시한다. 원본 없이 3D 값을 만들어내거나 몰래 2D로 대체하지 않는다.
- 실패한 계산은 0점/0°로 대체하지 않고 이유와 유효 프레임 수를 표시한다. IRER 주 계산이 불충분하면 기존 평가 보류 정책을 따른다.
- 프레임 각도·그래프·상세보기·대표사진 각도 영역·자동촬영·저장/복원/ZIP에 방식 선택을 일관되게 적용한다.
- 2D 수정과 3D 수정의 영향 범위를 구분한다. 비교에서는 동일 시각/같은 입력 영상·동일 분석 간격을 유지한다.
- 최대값 차이, 같은 프레임 차이, 기준각 오차를 혼동하지 않도록 표기한다. 두 값의 일치가 실측 정확도 증거는 아님을 안내한다.

## 결과 화면 디자인 검토안

모든 디자인은 한쪽 팔의 AB·FE2·BIR·IRER, 활성 동작 수 반영, 동작 의심도점수, 제한 적음/경도/중증도, 품질 별도 표시, 대표사진/스켈레톤/각도, 상세 수정/구간 재분석, 원본+결과 저장, 출력, 홈·이전 탐색을 유지한다. 질환 확률로 표현하지 않는다.

1. 한눈에 요약: 종합점수와 동작별 사진 카드. 빠른 이해를 우선.
2. 검사 리포트: 보고서 형태와 동작별 수치 표. 출력·기록에 적합.
3. 프레임 검토: 동작 목록/영상·프레임/계산 근거를 함께 배치. 분석 담당자 중심.
4. 단계 안내: 미확인 항목 → 확인 → 최종 저장 순서. 실수 방지 중심.
5. 동작 집중: 동작 탭과 큰 대표사진·핵심값. 한 동작씩 보기 편한 구성.

목업의 수치와 이미지 도식은 합성 예시이며 실측 또는 실제 검사 결과가 아니다. 사용자 선택 전 운영 UI에 반영하지 않는다.

## 합격 조건

- 모드별 계산 선택/재계산/실패/재분석 필요/과거 기록 호환 테스트.
- 저장→복원 후 방식·보정·주 계산·동일 프레임 비교 재현.
- 비교 값을 점수에 이중 반영하거나 평균하지 않음.
- 최종 결과와 상세 편집/대표사진의 방법 표시가 일치.
- 좁은 화면·키보드 접근·출력·미검출 상태 검증.
- 기능 검증과 실측 정확도 검증은 분리한다.
