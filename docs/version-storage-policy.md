# 버전 저장 규칙

사용자 확정일: 2026-10-04

- GitHub 저장소: https://github.com/ai-ssam/sho_gpt-v1
- 개발 중 변경은 work/vX.Y.Z 브랜치에 커밋·푸시하여 중간 이력을 보존한다. 커밋되지 않은 파일이 자동으로 GitHub에 동기화되는 것은 아니다.
- 기능 확인 전에는 작업본으로 표시하고 운영 main에 병합하거나 확정 릴리스 태그를 붙이지 않는다.
- 사용자가 기능을 확인한 뒤 명시적으로 “저장해”라고 요청하면 해당 버전명으로 새로운 로컬 폴더를 만들고, 기존 소스는 별도 보관한다.
- 새 로컬 버전 폴더·이전 소스 보관은 확인 후 저장 지시 전에는 수행하지 않는다. 현재 폴더 이름이 v4.0.2이어도 내부의 개발 버전은 package.json을 따른다.
- 로컬 보관 시 원본 폴더는 덮어쓰거나 삭제하지 않고, 복사 대상 경로와 버전을 확인한다. node_modules 및 환자 영상·결과 데이터는 소스 보관 대상에서 제외한다.
- 확인 완료 버전은 Git 커밋과 vX.Y.Z 태그로 고정한다. 동일 버전 태그가 존재하면 덮어쓰지 않고 새 패치 버전을 사용한다.
- main 병합과 운영 사이트 배포는 별도 요청이 있을 때 수행한다.

현재 기준: 기존 main 커밋 1936c270ba236399a8939cb9985a8bbef3e2f33c는 v4.0.2 보관본. v5.0.0은 기능 확인 전 작업본이다.
