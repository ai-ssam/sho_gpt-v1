# v5.2 추가사항 구현 기록

작성일: 2026-10-04. 앱 버전 5.2.0. 사용자 요청에 따라 별도 로컬 폴더 생성, 기존 v4.0.2 이름의 v5.0.0 소스 보존.

## 이번 구현

1. 별도 관리자 화면, 카메라 상세 기본 설정 이동.
2. 중립자세 입력: 카메라 또는 업로드 영상. 영상 프레임 전후 이동, 선택 화면 고정, 관절점 검출·수동 좌표 편집.
3. 기준 버전: IndexedDB 별도 DB에 이미지·원본/수정 관절점·특징값·출처·시각·프레임·허용값 저장. 기존 버전을 덮어쓰지 않고 새 ID로 추가. 동작·팔별 버전 선택.
4. 자동촬영: 기본 조건 또는 선택한 중립자세 템플릿 적용. 시작/복귀 유지시간 각각 설정. 검출 중단 시 누적 유지시간 초기화. 촬영 당시 설정과 기준 스냅샷을 결과에 보존.
5. 평가 표시: 문구와 두 경계값 편집·검증, 결과에 큰 글씨·초록/노랑/빨강 적용. 0≤점수<a / a≤점수<b / b≤점수≤100. 평가 보류는 별도 회색 상태. CSV와 결과 JSON에 표시 기준 포함.
6. 업로드: 카드 클릭 즉시 파일 선택. 등록 파일은 카드 목록 아래 별도 영역에 동작명·썸네일·이름·시간·해상도·용량·상태 표시.
7. BIR: 손목 고정. 손목 미검출 시 엄지 대체 없음. 기존 기록의 저장된 결과는 읽기만 할 때 유지되며, 다시 계산하면 손목 정책 적용.

## 실행 및 데이터

`npm ci` 후 `npm run dev`, http://localhost:4174/ 접속. 기존 4173 서버와 충돌하지 않는다. 웹 저장소는 포트별로 분리되므로 기존 검사 기록은 기존 버전에서 내보내 새 버전으로 복원해야 한다.

기준 등록 시 원본 영상 전체를 템플릿 저장소에 복제하지 않는다. 선택 이미지와 출처·특징값을 저장한다. 기준 촬영 카메라는 관리자 화면을 나갈 때 해제한다. 관리자 화면은 인증 기반 접근제어가 아니다.

## 검증 및 제한

재개 후 마무리: 카메라 장치 저장/미지원 설정 대체, 미저장 종료 안내, 최신 기준 재평가 이력·IRER 확인 초기화 및 품질 보류, 설정 복원 검증 보완. 최종 자동 테스트 49개 중 47개 통과·2개 건너뜀. 관리자 화면 브라우저 확인 및 오류 로그 없음. 자동 재개 예약 중지.

- 자동 테스트: 47개 중 45개 통과, 2개 샘플/도구 부재로 건너뜀. FE2 방향·양 극점·중간 중립 통과, BIR t 정수화, IRER 보정·불일치, 기존 기준 호환, 현재 검사 기준 보존·잘못된 복원 차단 포함. 업로드 → 스틸컷 → 관절점 수정 → 저장 → 적용 DOM 흐름에서 영상 디코딩과 모델 추론은 모의 처리한다.
- 브라우저: 별도 관리자 화면, 설정 필드, 잘못된 점수 경계 차단, 기본값 저장 확인. 확인 시 콘솔 오류 없음.
- 실제 인체 영상으로 기준 검출·자동촬영 정확도 및 임상적 점수 타당성은 아직 확인하지 않았다.
- 공통 중립 템플릿 비교는 2D 각도와 몸통 길이 정규화 특징 기반 시험 기능이다. IRER의 깊이 방향을 단일 2D 템플릿으로 검증했다고 주장하지 않는다.
- 추가 구현: 기본 AB·FE2·BIR·IRER 및 FE·ER·CIR 선택, FE2 방향성 전체 ROM·양 극점 편집/이미지 보존, BIR 손목 상대 높이 t·N 설정, IRER 개인 길이 보정과 보조 추정/품질 경고, 기본 팔/분석 간격, 설정·자세 기준 JSON 백업, 검사별 ID 보존 및 이전 저장소 마이그레이션.
- 브라우저 재검증: 기본 4동작 순서, BIR t 표시, 업로드 정보 하단 분리, 측정 화면 재생영역 숨김, 콘솔 오류 없음. 캐시된 이전 CSS가 남는 문제는 자산 쿼리 버전 갱신으로 수정.
- IRER 보조 추정은 가림 복원이나 의료적으로 검증된 3D 측정이 아니다. 손목 꺾임 등은 사용자 확인이 필요하며 보조값을 3D값과 임의 평균하지 않는다.
- 운영 main 병합·사이트 배포는 수행하지 않는다.
