## 1. 문서 해석 원칙

이 문서는 대화에서 합의한 목표 요구사항을 정의한다. 요구사항에 기재되어 있다고 현재 구현이 완료된 것은 아니다. 현재 상태는 12절에서 별도로 구분한다.

- **확정 요구사항**: 사용자와 합의한 제품 동작.
- **설계 제안**: 구현을 위한 권장 처리 방식. 사용자의 추가 결정이나 구현 검토에 따라 조정 가능.
- **시험 기준**: 코드에 적용 가능하지만 실제 측정·평가 타당성은 검증 전인 수치.

미확정 평가 임계값 때문에 화면·분석·저장 기능의 구현을 중단하지 않는다. 시험값을 명시하고 관리자에서 수정 가능하게 구현한다. 이 문서는 신규 임계값의 임상적 유효성을 확정하지 않는다.

## 2. 제품 목표와 범위

### 2.1 목표

- 한쪽 팔 검사에서 촬영·업로드·검토·저장을 일관된 흐름으로 제공한다.
- 동작당 1회 검사 후 재촬영을 선택할 수 있게 한다.
- 자동 관절점과 결과를 사용자가 확인·수정할 수 있게 한다.
- 검사별 설정을 보존하여 결과를 다시 해석할 수 있게 한다.
- 기본 프레임 분석과 선택 구간 정밀 분석으로 처리시간과 검토 편의성을 조절한다.

### 2.2 포함 범위

PC 브라우저 기반 로컬 실행, 카메라 입력, 영상 업로드, AB·FE2·BIR·IRER, 관리자 설정, 중립자세 템플릿, 자동·수동 촬영, 구간 편집, 결과 상세 수정, 평가점수, 결과·원본 저장, 내보내기·인쇄.

### 2.3 제외 범위

자동 의료 진단, 검증된 질환 확률, 양팔 동시 검사, 별도 요청 없는 클라우드 업로드·운영 배포. 로그인 기반 관리자 권한, 기관 간 데이터 공유, ZIP 직접 가져오기는 확정 범위가 아니며 별도 결정한다.

## 3. 화면 구성 및 이동

| 화면 | 핵심 내용 | 주요 이동 |
|---|---|---|
| 홈 | 카메라/업로드 선택, 진행 중·저장된 검사 접근 | 측정, 관리자 설정 |
| 카메라 측정 | 실시간 영상, 동작 선택, 촬영 상태·안내, 직접 촬영 옵션 | 결과, 홈, 이전 |
| 업로드 측정 | 동작 카드·파일 선택, 하단 별도 영역의 썸네일·파일정보·분석 상태 | 결과, 홈, 이전 |
| 분석결과 | 동작별 지표·점수·유효성, 종합 상태, 저장·출력 | 상세보기, 재촬영, 홈 |
| 동작 상세 | 영상 재생, 구간 지정, 프레임 이동·편집, 대표프레임·재분석 | 변경 적용 후 결과 |
| 관리자 설정 | 카메라 기본값, 동작·기준자세, 평가기준, 분석 간격, 기본 팔 | 이전 화면, 홈 |

NAV-01: 모든 주요 화면에 홈 또는 이전 단계 이동을 제공한다.  
NAV-02: 촬영·분석·미저장 수정 중 이동할 때 상태 손실 위험을 안내한다.  
NAV-03: 모드에 따라 대기 화면과 주요 행동 버튼을 다르게 구성한다.  
NAV-04: 관리자 화면은 측정 화면과 별도로 구성하고 기존 PC 설정 명칭을 관리자 설정으로 변경한다.

## 4. 검사 및 동작 관리

EXAM-01: 한 검사에서는 한쪽 팔만 측정한다. 관리자 기본 팔을 적용하되 검사 시작 시 변경할 수 있다.  
EXAM-02: 동작당 1회 수행하며 재촬영·파일 교체를 선택할 수 있다. 교체 시 기존 분석·수정값 영향 범위를 알린다.  
EXAM-03: 기본 활성 동작은 AB·FE2·BIR·IRER이다. FE·ER·CIR은 기본 숨김으로 유지한다.  
EXAM-04: 관리자는 동작별 활성 여부를 설정할 수 있다. 검사 완료 조건과 점수 계산은 활성 동작 목록을 기준으로 한다.  
EXAM-05: FE2와 FE·ER을 동시에 활성화할 때 동일 움직임의 중복 평가 가능성을 알린다. 자동 중복 제외 여부는 설계 결정 사항이다.  
EXAM-06: 과거 FE·ER·CIR 결과를 삭제하거나 FE2 결과로 자동 변환하지 않는다.

## 5. 촬영·업로드 요구사항

### 5.1 카메라

CAM-01: 장치, 해상도, FPS, 미리보기 반전, 카운트다운, 안내음 기본값은 관리자에서 설정한다. 지원되지 않는 장치 설정은 대체값과 사유를 안내한다.  
CAM-02: 측정 화면은 실시간 영상 중심으로 구성한다. 동작 선택, 시작·중지·재촬영, 자동/수동 선택, 안내음, 안내선 등 촬영에 직접 필요한 옵션만 노출한다.  
CAM-03: 중심선·수평선·촬영 영역·자세 안내를 선택박스로 제어한다. 반전 표시와 분석 좌표의 관계를 일관되게 처리한다.  
CAM-04: 카운트다운 및 촬영 시작·종료를 음성 또는 신호음으로 안내한다. 음소거 선택과 시각 안내도 제공한다.  
CAM-05: 카메라 측정 화면 하단의 녹화본 다시보기는 결과 상세보기로 이동한다.  
CAM-06: 자동 촬영 중에도 수동 중지를 제공한다. 권한 거부·장치 연결 해제·검출 실패를 사용자에게 알린다.

### 5.2 중립자세와 자동 촬영

NEU-01: 관리자에서 동작별 중립자세를 카메라 스틸컷 또는 업로드 영상에서 선택한 프레임으로 등록한다. 업로드 영상은 재생·일시정지·프레임 이동 후 기준 프레임을 선택하고, 두 입력 방식 모두 관절점 확인·수정 후 동일한 템플릿 저장 절차를 따른다.  
NEU-02: 이미지, 원본·수정 관절점, 측정 팔, 촬영 방향, 주요 각도·정규화 비율, 허용오차, 생성일, 템플릿 ID·버전을 저장한다. 입력 출처(카메라/업로드)를 기록하며 업로드는 원본 파일정보와 선택 프레임 번호·시각도 저장한다. 선택 이미지와 특징값은 원본 영상을 다시 연결하지 않아도 기준으로 사용할 수 있어야 한다.  
NEU-03: 템플릿 수정 저장 시 새 버전을 생성하고 기존 검사에 연결된 버전은 보존한다. 앱 버전·평가기준 버전·템플릿 버전은 별도로 관리한다.  
NEU-04: 자세 비교에는 픽셀 위치만 사용하지 않고 몸 크기로 정규화한 길이·각도를 사용한다. 다른 사람의 절대 팔 길이를 그대로 적용하지 않는다.  
NEU-05: 유효한 중립자세를 일정 시간 유지하면 카운트다운 후 촬영을 시작한다. 동작 수행을 확인한 뒤 초기 중립자세로 돌아와 일정 시간 유지하면 종료한다. 관리자 카메라 설정에서 자동촬영의 시작 전 중립자세 유지시간과 복귀 후 종료 유지시간을 초 단위로 각각 설정한다. 유지시간은 카운트다운 시간과 구분하고 해당 검사 설정 스냅샷에 보존한다. 유지시간·허용오차는 수정 가능한 시험 설정이다.  
NEU-06: FE2는 뒤쪽과 위쪽 동작을 모두 확인하기 전에는 중간 중립자세 통과를 종료로 판단하지 않는다.  
NEU-07: 자세를 놓쳤거나 신뢰도가 낮으면 중립자세 충족으로 처리하지 않는다. 안내·재시도·수동 촬영을 제공한다.  
NEU-08: 공통 자세 템플릿과 개인별 IRER 길이 보정값을 분리한다. 기준자세 등록은 학습 모델 재훈련을 뜻하지 않는다.

### 5.3 업로드

UP-01: 사용자가 동작 카드를 클릭하면 해당 동작의 파일 선택창을 즉시 연다.  
UP-02: 등록 후 썸네일, 파일명, 재생시간, 해상도, 용량, 분석 상태를 동작 카드 내부가 아닌 카드 목록 하단의 별도 파일정보 영역에 표시한다. 각 파일정보에는 연결된 동작명을 명시하고 교체 조작을 제공한다. 동작 카드는 동작 선택·파일 등록 진입 역할을 유지한다.  
UP-03: 선택 취소는 기존 파일을 유지한다. 지원하지 않거나 손상된 영상에는 오류를 표시하고 재선택을 제공한다.  
UP-04: 카메라 모드와 동일하게 기본 선택 동작은 AB·FE2·BIR·IRER이다.

## 6. 동작별 측정 요구사항

### 6.1 AB

M-AB-01: 정면 외전 동작에서 몸통과 측정 상완을 기준으로 각도를 측정한다. 최대값과 대표프레임을 저장하고 수동 수정할 수 있다. 몸통 기울기와 관절 가림은 품질 확인 대상으로 표시한다.

### 6.2 FE2

M-FE2-01: 측면에서 중립 → 최대 뒤쪽 신전 → 최대 위쪽 굴곡 → 중립 순서로 수행한다.  
M-FE2-02: 방향을 구분한 각도로 뒤쪽 극점부터 위쪽 극점까지 전체 가동범위를 계산한다. 단순한 0~180° 무방향 각도의 최댓값-최솟값만으로 계산하지 않는다.  
M-FE2-03: 신전 극점과 굴곡 극점의 각도·시각·대표프레임을 각각 저장하고 전체 범위를 별도로 표시한다.  
M-FE2-04: 좌우 팔, 촬영 방향, 반전에 대해 방향 부호와 각도 연속성이 일관되어야 한다. 어느 한 극점이 없으면 불완전 측정으로 표시한다.  
M-FE2-05: 평가점수 경계값은 관리자에서 변경 가능한 시험 기준으로 구현한다.

### 6.3 BIR

M-BIR-01: 관리자가 골반선부터 어깨선 사이 분할 수 N을 양의 정수로 지정한다. N=10이면 골반선 t0, 어깨선 t10이다.  
M-BIR-02: 도달 높이를 구간에 비례해 계산하고 정수 t값으로 표시한다. 골반 아래는 t-1 등 음수, 어깨 위는 t11 등 N 초과 값도 허용한다.  
M-BIR-03: 원시 연속값, 표시 정수, 분할 수, 참조 관절점과 손 위치를 함께 저장한다. 척추 분절 T1~T12와 혼동되지 않게 소문자 t를 사용한다.  
M-BIR-04: 도달 높이 대표프레임과 최소 팔꿈치각 대표프레임은 별도로 유지한다.  
M-BIR-05: 도달 높이 추적 기준점은 측정 팔의 손목으로 고정한다. 엄지나 손끝으로 자동 대체하지 않는다. 손목 검출이 불충분하면 검토 필요로 표시하고 상세보기에서 수정할 수 있게 한다. 저장 데이터에 기준점 wrist를 명시하고 과거 다른 기준점 결과와 구분한다.  
M-BIR-06: 정수화는 최근접 반올림을 제안한다. 음수의 정확한 반올림 규칙까지 구현 명세·테스트에서 고정한다.

계산 설계 제안: 손 기준 위치에서의 골반선 높이를 yP, 어깨선 높이를 yS, 손 높이를 yH라 할 때 화면 아래쪽이 +y인 좌표에서 `tRaw = N × (yP - yH) / (yP - yS)`로 정규화한다. 몸통 기울기는 양측 어깨·골반선으로 보정하는 방식을 검토한다. 분모가 너무 작거나 기준점이 불명확하면 무효 처리한다. 이 식은 임상 척추 수준 추정식이 아니다.

### 6.4 IRER

M-IRER-01: 정면에서 측정 팔꿈치를 몸통 옆에 붙이고 약 90° 굽힌 자세로 외회전한다. 반대 팔은 곧게 내린다.  
M-IRER-02: 몸통 기준 3D 관절점 추정 각도를 기본 경로로 유지하고 길이 보정 기반 추정을 보조 경로로 추가한다.  
M-IRER-03: 반대 팔의 어깨~팔꿈치 길이는 체격·화면 배율 변화의 보조 기준으로 사용한다. 상완 길이가 측정 팔 전완 길이와 같다고 가정하지 않는다.  
M-IRER-04: 측정 전완이 영상면과 평행한 보정 자세에서 팔꿈치~손목 길이를 등록하는 방식을 제공한다. 주먹 끝 기준 사용 시에는 팔꿈치~주먹 끝 길이를 별도로 보정한다.  
M-IRER-05: 보정 길이 대비 손의 좌우 이동량으로 외회전을 보조 추정할 수 있으나, 원근·몸통 회전·팔꿈치 이동의 영향을 품질 조건으로 검사한다. 단일 정면 영상만으로 가려진 손의 실제 3D 위치를 확정하지 않는다.  
M-IRER-06: 직접 검출점, 사용자 수정점, 추정점을 화면과 데이터에서 구분한다. 3D값과 보조 추정값의 차이가 허용값보다 크면 검토 필요로 표시한다.  
M-IRER-07: 팔꿈치 몸통 이탈, 팔꿈치 각도 변화, 어깨 들림, 몸통 회전, 손목 굽힘을 확인 대상으로 둔다. 보정 실패 시 값을 임의 확정하지 않는다.  
M-IRER-08: 보정값·방법·사용 기준점·품질 상태를 검사별로 저장한다. 오차 허용값은 시험값으로 설정 가능하게 한다.

자세 참고로 사용자가 제시한 자료: https://pmc.ncbi.nlm.nih.gov/articles/PMC3826176/ 의 Figure 4a. 해당 자료의 자세 참조와 앱 측정 알고리즘·점수의 검증은 별개이며, 이 문서 작성에서는 자료를 재검토하지 않았다.

## 7. 분석 및 상세 편집

ANA-01: 기본 분석 프레임 간격을 관리자에서 지정한다. 현재 코드 기본값 3프레임은 기존값이며 고정 제품 제약은 아니다.  
ANA-02: 상세보기에서는 먼저 분석된 프레임 사이를 앞뒤 이동한다. 원본 연속 프레임 검토가 필요하면 선택 구간을 정밀 재분석한다.  
ANA-03: 수동 촬영 영상의 시작·종료 시점을 편집하여 분석구간을 지정한다. 원본은 보존하고 구간 메타데이터를 저장한다.  
ANA-04: 프레임별 관절점과 대표프레임을 수정하고 적용하면 관련 동작 지표와 최종 점수를 재계산한다.  
ANA-05: 자동값, 수정값, 최종값을 구분하고 자동값으로 복원할 수 있게 한다. IRER에서 2D 수정과 3D 수정의 영향도 구분한다.  
ANA-06: 정밀 재분석은 기존 수동 수정값을 보존하는 것을 기본으로 한다. 구간 전체 재설정 등 보존 불가능한 작업은 적용 전에 초기화 범위를 확인받는다.  
ANA-07: 분석 실패·취소·검출점 부족을 완료로 표시하지 않고 재시도할 수 있게 한다.

## 8. 관리자 설정 및 평가

ADM-01: 카메라 기본 설정, 동작 활성화, 중립자세 템플릿, 평가기준, 기본 분석 간격, 기본 측정 팔을 별도 관리자 화면에서 관리한다.  
ADM-02: 평가기준을 표로 편집하고 CSV로 가져오기·내보내기 한다. 설정 전체의 JSON 백업·복원은 설계 제안이다.  
ADM-03: 가중치 합계, 누락 동작, 구간 경계·중복, 분할 수, 음수·비정상 입력을 검사하고 오류가 있는 설정은 적용하지 않는다.  
ADM-04: 설정은 PC의 해당 브라우저에 보관한다. 다른 브라우저·PC에 자동 동기화된다고 표시하지 않는다.  
ADM-05: 저장된 검사에는 적용 당시 설정 스냅샷을 보존한다. 최신 설정으로 재평가할 때는 명시적 선택과 새 결과 이력을 남긴다. 진행 중 검사에 설정을 바꾸는 경우에도 적용 여부를 안내한다.

ADM-06: 카메라 설정에 자동촬영 중립자세 유지시간(시작 전/복귀 후)을 추가하고 양의 유한한 초 단위 값인지 검증한다.  
ADM-07: 평가기준에 동작 의심도점수의 3단계 표시 구간 설정을 추가한다. 기본 문구는 제한 적음·경도·중증도, 대응 색상은 초록·노랑·빨강이다. 문구와 두 점수 경계값을 편집하며 전체 0~100점을 누락·중복 없이 분류해야 한다. 경계값 a, b는 0 < a < b < 100으로 검증하고 구간은 [0,a), [a,b), [b,100]으로 정의한다. 구체적인 초기 경계값은 시험값으로 제공하고 설정 버전에 포함한다.

SCORE-01: 결과 명칭은 동작 의심도점수, 단위는 0~100점이다. 백분율 기호나 질환 확률로 표현하지 않는다.  
SCORE-02: 동작별 측정값·점수·가중치·품질 상태를 표시하고 종합 결과를 제공한다.  
SCORE-03: 동작 의심도점수에 따라 제한 적음(초록)·경도(노랑)·중증도(빨강)의 3단계를 큰 글씨와 색상으로 표시한다. 기존 위험·주의·안심 문구를 이 기본 문구로 대체한다. 관리자에서 정한 문구·점수 구간을 적용하고 숫자 점수를 함께 표시한다. 점수가 높을수록 높은 제한 단계에 해당한다. 색상만으로 구분하지 않으며 노란색 단계도 읽기 쉬운 글자 대비를 확보한다. 구간 판정은 표시용 반올림 전 최종 점수를 사용하고 화면에서도 경계 판단을 오해하지 않도록 정밀도를 표시한다. 임상 미검증 시험 기준에 따른 동작 제한 단계이며 질환 진단이나 의학적 중증도 확정이 아님을 안내한다. 평가 보류는 3단계 중 어느 것으로도 분류하지 않고 별도 상태로 표시한다.  
SCORE-04: 필수 활성 동작이 누락·무효·검토 대기라면 종합 평가를 보류한다. 누락된 동작을 0점이나 정상으로 처리하거나 임의로 가중치를 재분배하지 않는다.  
SCORE-05: 기존 FE·ER·척추 수준 BIR 점수표를 FE2·t구간 BIR에 그대로 전용하지 않는다. 새 기준 버전으로 구분한다.

점수 산식 설계 제안: 동작별 등급 s가 0~3이고 가중치 w의 합이 100일 때 `종합점수 = Σ(w × s / 3)`으로 계산한다. 기존 구현과 호환되는 제안이며, 목표 동작의 가중치·경계값은 별도 시험 기준표로 정의한다. FE2, 변경된 BIR, IRER 허용오차의 구체적인 신규 수치는 아직 확정되지 않았다. 구현자는 시험값임을 표시한 초기 설정을 제공하되 검증된 기준으로 주장하지 않는다.

## 9. 결과 및 데이터 저장

DATA-01: 촬영 직후 원본 Blob을 우선 메모리에 유지해 분석하고 사용자 저장 요청 시 원본과 결과를 함께 저장한다. 브라우저 종료 전 미저장 데이터 손실을 안내한다.  
DATA-02: 브라우저 저장과 PC 파일 내보내기를 구분한다. IndexedDB도 영구 보장이 아니며 브라우저 데이터 삭제·저장 용량 제한에 영향을 받는다.  
DATA-03: 저장 성공 여부를 확인한 뒤 성공으로 표시하고 실패 시 재시도·파일 내보내기 경로를 제공한다.  
DATA-04: 결과 화면은 별도 구성하며 동작별 상세보기, 최종 점수, 검토 상태, 저장·인쇄를 제공한다.  
DATA-05: 결과와 원본을 함께 내보내며, 결과만 내보내는 경우 원본이 포함되지 않았음을 알린다.  
DATA-06: 사용자 정보와 영상은 기본적으로 외부 서버에 전송하지 않는다. 소스 저장소에 실제 검사 영상을 포함하지 않는다.

검사별 최소 보존 항목:

- 검사 ID, 생성·수정 시각, 측정 팔, 입력 모드, 앱·데이터 형식 버전.
- 활성 동작 목록, 평가기준·가중치 스냅샷, 중립자세 템플릿 버전·특징값, 개인 보정값.
- 원본 영상 및 파일정보, 분석구간, 프레임 간격, 프레임의 원본 시각·번호.
- 원본·수정·추정 관절점 및 종류, 품질·유효성 상태.
- 자동·수동·최종 측정값과 대표프레임, FE2 양 극점, BIR 연속·정수값 및 N.
- 동작별 점수, 종합 점수, 평가 보류 사유, 수정 이력.

설계 제안: 환자 ID와 검사 ID를 분리하여 같은 사람의 반복 검사가 기존 검사를 덮어쓰지 않게 한다. 현재 코드의 환자 ID 기반 갱신 동작과 달라지는 부분이므로 데이터 이관·저장 UX 설계에서 명시한다.

## 10. 성능·안정성·사용성

NFR-01: GPU 추론을 우선 시도하고 미지원·초기화 실패 시 CPU로 전환한다. 실제 사용 경로와 처리 상태를 표시한다.  
NFR-02: Worker, 모델 재사용, 필요한 동작에만 손 검출, 기본 간격 분석·선택 구간 재분석을 활용한다.  
NFR-03: 메모리 사용량에 맞춰 프레임·동시 작업 수를 제한한다. 사용이 끝난 영상 URL·프레임·모델 자원을 해제한다. CPU/GPU 100% 점유 자체를 목표로 삼지 않는다.  
NFR-04: 긴 처리 중에도 진행 상태·오류·취소 가능 여부를 표시한다. UI가 멈춘 것처럼 보이지 않게 한다.  
NFR-05: 경고는 색상만이 아니라 텍스트로도 제공하고 소리 안내에는 시각 안내를 병행한다.  
NFR-06: 카메라 권한은 사용자가 연결을 선택할 때 요청한다. 영상 분석에 불필요한 마이크 녹음은 하지 않는다.

처리시간·메모리 상한·각도 오차의 정량 합격 수치는 현재 미확정이다. 실제 대상 PC와 테스트 영상으로 기준선을 측정한 뒤 결정하며 성능 향상을 사전 보장하지 않는다.
