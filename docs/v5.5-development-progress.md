# v5.5 개발 진행·인수인계

요청: '한눈에 요약' 결과 화면과 IRER 2D/기존3D/비교 선택 구현. 원본 v5.4와 운영 main은 보존.

## 구현

- `irer-methods.mjs`: 기본2D, 기존3D 조건 보존, 비교 주 계산, 동일 프레임과 별도 최대값, 실패/재분석 안내, 방식별 ID/버전.
- 관리자 설정/백업·복원, 검사별 설정 저장, 방식 변경 이력/확인 초기화. 기존 2D/3D 데이터의 의미를 유지한다.
- 새 촬영/분석은 필요한 모드에서만 3D 좌표 보존. 현재 프레임·그래프·대표사진·자동 촬영은 주 계산과 일치. 2D와 3D 좌표 편집의 영향 분리.
- `results-overview.mjs/css`: 종합 단계/평가보류, 대표사진·측정값·개별점수·품질 카드, 상세 수정 연결. 기존 내보내기/출력/저장 유지.
- 비교 상세: 현재 프레임 각도/차이/실패 사유, 서로 다른 최대각 프레임, 30개씩 비교 표 탐색, 비교 계산 점선 그래프.

## 검증

- `npm test`: 57개 중 55 통과, 2개 실제 영상/도구 부재 건너뜀.
- 신규 모드 테스트: 평균하지 않음, 주 계산 점수, 3D 결측 시 자동 대체 금지, 서로 다른 극점, 기존 90° 경계 보존, 반전/2D좌표 수정/레거시.
- DOM 통합: 설정3D→비교 전환, 확인초기화/이력, JSON 저장·복원 검증, 요약 카드, 상세 비교/3D 편집 표시.
- 실제 브라우저: 포트4176 앱 초기화 및 관리자 비교 선택/설정 저장 성공.
- **미검증**: 검사 JSON 복원 이후 결과 사진·비교 상세의 실제 브라우저 시각 검증, 모바일·출력 시각 검증. 파일 선택 도구 연결 만료 후 CDP 복구도 시간 초과되어 더 진행하지 않았다. 자동 테스트 성공을 실브라우저/실영상 검증으로 주장하지 않는다.
- 실제 촬영·각도계 정확도 미검증. 샘플은 `test-output/overview-synthetic.json` (로컬 전용 합성 자료, 실제 환자 아님, Git 제외).

## 재개 시

1. 이 폴더에서 npm run dev → localhost:4176.
2. 브라우저 연결 복구 후 합성 JSON 복원/불러오기. 원본이 없는 경우 사진 없음 안내가 정상이다. 실제 사진·원본 연결 케이스는 별도 영상으로 확인.
3. 관리자 모드와 상세 비교·동일 프레임 이동, 결과 카드, 좁은 화면, 출력 레이아웃을 확인하고 문제 있으면 개발 브랜치에서 수정.
4. 사용자 기능 확인 전 정식 버전/운영 main으로 교체하지 않는다.
