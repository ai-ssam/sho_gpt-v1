# Shoulder ROM Lab — 프로젝트 개요

작성일: 2026-10-04  
문서 버전: 1.1  
현재 코드 버전: v5.0.0 개발 작업본  
대상: 프로젝트 소유자, 개발자, 후속 AI 개발 세션

## 1. 프로젝트 정의

Shoulder ROM Lab은 한쪽 팔의 어깨 동작을 카메라로 촬영하거나 기존 영상을 업로드하여, 관절점 기반으로 가동범위와 동작별 지표를 분석하고 사람이 검토·수정·저장하는 PC 중심 로컬 웹 애플리케이션이다.

핵심은 촬영에서 끝나는 앱이 아니라, 영상 입력 → 자동 분석 → 대표프레임 검토 → 관절점 수정 → 결과 재계산 → 원본과 결과 저장까지 연결하는 것이다.

결과 명칭은 **동작 의심도점수**다. 0~100점은 설정된 시험 평가기준에 따른 점수이며, 오십견 발생 확률이나 확정 진단을 의미하지 않는다. 관리자에서 설정한 점수 구간에 따라 **제한 적음(초록)·경도(노랑)·중증도(빨강)**를 큰 글씨와 색상으로 표시한다. 이 단계는 의학적 중증도 확정이 아닌 시험 기준의 동작 제한 분류다.

## 2. 해결하려는 문제

- 카메라 촬영과 영상 업로드 흐름이 섞여 사용자가 다음 행동을 파악하기 어렵다.
- 촬영 자세와 시작·종료 시점이 일정하지 않으면 분석 비교가 어렵다.
- 자동 관절점 검출의 오류를 사람이 확인하고 결과에 반영할 수 있어야 한다.
- 평가기준을 코드 수정 없이 변경하고, 어떤 기준으로 산출된 결과인지 추적해야 한다.
- 전체 영상을 매번 정밀 분석하는 비용을 줄이면서 필요한 구간은 자세히 검토해야 한다.

## 3. 사용자와 역할

| 역할 | 주요 목적 |
|---|---|
| 검사 진행자 | 측정 팔 선택, 촬영 또는 업로드, 분석 확인, 재촬영 |
| 결과 검토자 | 대표프레임·관절점 검토 및 수정, 최종 결과 확인·출력 |
| 관리자 | 카메라 기본값, 동작 활성화, 기준자세, 평가기준·가중치 설정 |

한 사람이 모든 역할을 수행할 수 있다. 관리자 화면 분리는 기능 구분이며, 로그인·권한 인증 구현은 현재 확정 범위가 아니다.

## 4. 목표 사용 흐름

1. 홈에서 카메라 또는 업로드 모드를 선택한다.
2. 검사정보와 측정할 한쪽 팔을 확인한다.
3. 기본 동작 AB·FE2·BIR·IRER을 각각 1회 기록한다. 필요하면 해당 동작만 재촬영·교체한다.
4. 기본 간격으로 추출한 프레임을 먼저 분석한다.
5. 별도 결과 화면에서 동작별 지표와 평가 상태를 확인한다.
6. 상세보기에서 분석구간, 관절점, 대표프레임을 수정하거나 필요한 구간을 정밀 재분석한다.
7. 수정된 최종 결과와 원본 영상을 함께 저장하고 필요하면 내보내기·인쇄한다.

## 5. 기본 측정 동작

| 동작 | 목표 측정 내용 | 촬영 방향 |
|---|---|---|
| AB | 팔을 옆으로 들어 올리는 외전 가동범위 | 정면 |
| FE2 | 팔의 최대 뒤쪽 신전부터 최대 위쪽 굴곡까지의 전체 가동범위 | 측면 |
| BIR | 등 뒤 측정 팔 손목의 도달 높이를 골반선 t0~어깨선 tN의 상대 구간으로 표현 | 후면 |
| IRER | 팔꿈치를 몸통 옆에 붙이고 90° 굽힌 상태에서 바깥쪽으로 벌리는 외회전 | 정면 |

기존 FE·ER은 기본 화면에서 숨기고 FE2로 통합한다. 이 프로젝트의 기존 ER 코드는 신전 동작을 의미하며, 일반적인 외회전 약어와 혼동하지 않는다. 외회전 동작 코드는 IRER이다. CIR은 기본 숨김·보류하고 과거 데이터 호환성을 유지한다.

## 6. 핵심 제품 원칙

- 촬영 화면에는 촬영에 직접 필요한 조작만 둔다. 상세 설정은 관리자 화면으로 이동한다.
- 자동 분석 결과는 검토·수정할 수 있고, 자동값·수동값·최종값을 구분한다.
- 영상은 우선 메모리에서 처리하고, 사용자가 저장을 선택하면 원본과 결과를 저장한다.
- 메모리 우선은 앱의 명시적 파일 저장을 하지 않는다는 의미다. 운영체제·브라우저의 스왑이나 내부 임시 저장까지 금지한다는 보장은 아니다.
- GPU 우선 추론과 CPU 대체 경로를 사용하되, 자원을 무조건 최대 점유하지 않고 응답성과 안정성을 확보한다.
- 적용된 평가기준·중립자세·보정값을 검사별로 보존한다.
- 중립자세 기준은 카메라 스틸컷 또는 업로드 영상의 선택 프레임으로 등록한다. 자동촬영 시작 전·복귀 후 중립자세 유지시간은 관리자에서 설정한다.
- 업로드 동작 카드는 파일 선택 진입점으로 사용하고, 썸네일·파일정보는 카드 목록 하단의 별도 영역에 표시한다.
- 미완료·저품질·미검증 추정치를 정상 결과나 안심으로 처리하지 않는다.

## 7. 현재 상태와 다음 개발 범위

2026-10-04 로컬 README, package.json, v5-core.mjs, v5-ui.mjs를 확인한 기준이다. 이번 문서 작성에서 실제 카메라 테스트나 전체 테스트를 재실행한 것은 아니다.

현재 v5.0.0에는 카메라/업로드 모드, AB·FE·ER·BIR·IRER 분석 흐름, 시험 자동촬영, 프레임 편집, 구간 재분석, 점수 설정, 원본·결과 저장 기능이 있다.

다음 개발의 핵심은 별도 관리자 화면, FE2 통합, BIR t구간, 버전별 중립자세 스틸컷, IRER 보정 보조 방식, 모드별 측정 화면 개선이다. 구체적인 요구사항과 합격 조건은 [PRD](PRD.md)에 정의한다.

## 8. 범위 밖 및 검증 경계

확정 진단, 임상적으로 검증된 질환 확률 제공, 모든 하드웨어에서 동일한 정확도·속도 보장, 클라우드 환자정보 전송, 양팔 동시 검사는 현재 목표가 아니다.

기능 구현과 검증은 구분한다. 미확정 점수표·오차 허용값은 수정 가능한 시험값으로 구현할 수 있다. 단, 실제 측정 정확도와 임상적 타당성이 검증된 것처럼 표시하지 않는다.
