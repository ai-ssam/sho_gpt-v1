# IRER 정면 2D 길이비 계산 (2026-10-05)

현재 IRER 계산 방법 ID: `irer-2d-asin-v1`. 영상에서 검출/수정한 2D 관절점만 사용한다. Pose 모델의 world/depth 좌표는 IRER 각도, 최대각 선택, 자동 촬영 판단에 사용하지 않는다. 기존 저장자료의 3D 좌표는 삭제하지 않지만 새 계산에서 무시한다. 2D 관절점 자동 검출 자체에는 기존 Pose 모델을 계속 사용한다.

## 길이·각도 계산

1. 정면에서 측정팔은 팔꿈치를 몸통 옆에 붙이고 90° 굽혀 전완을 수평으로 유지한다. 반대팔은 곧게 내린다.
2. 측정팔 어깨 S, 팔꿈치 E, 손목 W와 반대팔 어깨/팔꿈치/손목을 추적한다. 좌우 방향은 양쪽 어깨의 영상상 위치로 결정하므로 반전 영상에도 적용된다.
3. 정규화 좌표는 가로에 영상 가로/세로 비율을 곱해 길이 단위를 맞춘다. 어깨를 지나는 세로선, 팔꿈치 높이 가로선을 표시한다.
4. 이동량 d는 어깨가 아니라 **팔꿈치부터 손목까지의 바깥쪽 가로 거리**다. 어깨 기준 손목 이동량에서 어깨 기준 팔꿈치 이동량을 빼는 것과 같다. 팔꿈치 이탈은 별도 제한으로 검사한다.
5. 개인 보정이 없으면 곧게 내린 반대팔 팔꿈치–손목의 2D 길이를 L로 사용한다. 좌우 전완 길이가 같고 반대팔이 영상면에서 곧게 내려져 있다는 가정이며 '반대팔 전완 참조'로 표시한다. 반대팔 상완 길이를 전완 길이로 대입하지 않는다.
6. 개인 보정이 있으면 영상면과 평행한 측정팔 전완의 기준 길이 L0를 사용한다. 현재 반대팔 어깨–팔꿈치 길이 / 보정 시 반대팔 어깨–팔꿈치 길이 = scale. L = L0 × scale. 주먹 끝을 선택하면 기준 길이와 이동량 모두 팔꿈치–수동 지정 주먹 끝으로 통일한다.
7. r=d/L, θ=asin(r)×180/π. 0≤r≤1인 경우만 계산한다. 0, 0.5, 약 0.866, 1은 각각 0°, 30°, 60°, 90°다. 범위 밖을 무조건 0°/90°로 자르지 않고 오류 사유를 표시한다.
8. 유효 분석 프레임 중 최대 θ를 최대 외회전각 및 자동 대표 프레임으로 선택한다. 프레임별 길이·비율·계산 방법·경고를 결과 JSON에 보존한다. 현재 안정 구간 평균/중앙값 선택은 적용하지 않았다.

## 검사 조건과 제한

- 필요한 관절점은 visibility≥0.45 또는 수동 지정이어야 한다.
- 반대팔 상완/전완의 가로 벗어남은 각 길이의 35% 이내, 아래쪽 방향이어야 한다.
- 측정팔 팔꿈치의 어깨 세로선 이탈은 반대팔 상완 길이의 30% 이내다.
- 손 기준점 높이는 팔꿈치 높이에서 L의 25% 이내다. 이 조건은 전완 수평의 영상상 검사이며 실제 팔꿈치 굽힘 90°를 독립적으로 입증하지 않는다.
- 양쪽 어깨 높이 차이는 반대팔 상완 길이의 20% 이내다.
- 개인 보정 거리 변화 기본 허용은 25%, 보정된 어깨 폭 차이가 20%를 넘으면 확인 필요로 표시한다.
- r>0.95에서는 90° 근처 오차 민감 경고를 표시한다. 단일 정면 영상과 asin만으로 90° 초과 여부는 판별할 수 없다.
- 영상 투영·좌우 신체 차이·관절점 오차가 각도에 영향을 준다. 위 검사 수치는 임상 검증된 허용값이 아닌 구현 시험값이다. 2D 계산이라고 직접 실측이나 의학적 정확성이 보장되는 것은 아니다.
- 예전 3D 결과는 원본 연결 후 구간 재분석 또는 상세보기 재계산으로 새 방법을 적용하고 확인 후 저장한다. 기존 저장 검사는 자동 덮어쓰지 않는다.

## 테스트

합성 좌표 0/30/60/90°, 좌우/반전, 화면 비율, 개인 보정, 2D 수동 수정, 기준 길이 초과, 팔꿈치 이탈, 반대팔 자세 실패 및 world 좌표 없는 분석을 검증한다. 실제 촬영 영상·각도계 비교는 별도 검증 필요.
