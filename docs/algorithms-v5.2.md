# v5.2 관절 추출·측정 알고리즘

2026-10-04 코드 기준. 동작별로 다른 AI를 학습한 것이 아니라 MediaPipe Pose Landmarker Lite의 공통 추출 결과에 동작별 기하 계산을 적용한다. 2D 정규화 좌표와 모델 추정 world 3D 좌표를 별도로 보존한다. 화면 좌표 계산에는 영상 가로세로 비율을 적용한다. 검출 신뢰도가 부족한 점은 유효 측정에서 제외하며 원본과 수동 수정값을 분리한다.

| 동작 | 측정 경로 |
|---|---|
| AB | 정면, 어깨→골반 몸통 벡터와 어깨→팔꿈치 상완 벡터 사이 2D 각도 |
| FE2 | 측면, 몸통·상완의 atan2 방향성 각도와 시간 연속성 보정. 뒤쪽 음수 신전부터 앞쪽 양수 굴곡까지 max−min. 극점 순서와 양쪽 움직임 필요 |
| BIR | 후면, 손목 위치에서 양쪽 골반선·어깨선을 평가. tRaw=N×(골반Y−손목Y)/(골반Y−어깨Y). 가장 가까운 정수, 정확히 절반은 0에서 먼 쪽으로 반올림. t-1/t11 등 허용 |
| IRER | 몸통 기준 world 3D 전완 방향을 기본 외회전 추정값으로 사용. 별도 개인 길이 보정 후 asin(손의 바깥쪽 이동량/보정 전완 길이)을 보조값으로 비교 |
| FE·ER | 이전 개별 굴곡·신전 2D 경로 유지. 기본 숨김 |
| CIR | 이전 Pose+Hand Landmarker 엄지끝 추적·원 적합 경로 유지. 기본 숨김·보류 |

BIR 최소 팔꿈치각은 최대 손목 높이와 다른 프레임으로 저장한다. t는 척추 번호가 아니다. FE2의 촬영 방향은 반전 미리보기가 아닌 원본 영상 기준으로 설정하며 양 극점을 상세보기에서 직접 지정할 수 있다. 자동 촬영은 신전 다음 굴곡을 확인한 뒤 중립 복귀에서 종료하므로 중간 중립 통과에서는 끝나지 않는다.

## IRER 보정과 한계

전완이 영상면과 평행한 프레임에서 측정팔 팔꿈치–손목 길이를 등록한다. 반대팔 어깨–팔꿈치 길이는 촬영 배율 변화 보조 기준이지 전완 길이 대체값이 아니다. 주먹 끝은 수동 지정한 끝점까지 별도 보정한다. 상세보기에서 두 추정값과 차이·경고를 표시하고 개인 보정/추정점/수정 이력을 저장한다. 검출점은 추정점으로 덮어쓰지 않는다.

거리 변화, 어깨 폭 변화(몸통 회전 가능성), 팔꿈치 이탈, 전완 수평 이탈, 어깨 기울기, 3D와 보조값 불일치를 경고한다. 깊이 부호·가려진 손의 실제 위치를 단일 영상만으로 확정하지 않는다. 손목 꺾임과 정확한 90° 유지 여부는 사용자 확인이 필요하다. 보조값은 0~90° 범위의 단순 투영 모델이며 3D값과 자동 평균하지 않는다. 추정 확인 전에는 IRER 점수 반영을 보류한다.

## 초기 시험 기준 (의학적 정상값 아님)

| 동작 | 가중치 | 0점/1점/2점 하한 (그 미만 3점) |
|---|---:|---|
| AB | 25 | 150 / 120 / 90° |
| FE2 | 35 | 200 / 160 / 120° |
| BIR (N=10) | 15 | tRaw 8 / 5 / 2 |
| IRER | 25 | 60 / 40 / 20° |

동작 등급 0~3을 가중 합산하여 0~100점으로 표시한다. 기본 3단계는 20점 미만 제한 적음(초록), 20~50점 미만 경도(노랑), 50점 이상 중증도(빨강). 문구와 경계는 관리자에서 수정한다. 질환 확률·오십견 진단이 아니다. FE2/BIR 초기 기준은 실행 가능한 시험 설정이며 임상 타당성은 검증되지 않았다. IRER 차이 허용 15°, 거리 변화 허용 0.25도 조정 가능한 시험값이다.

## 성능·저장·검증

GPU 우선 초기화, 실패 시 CPU 경로, Worker 추론·모델 재사용·분석 큐·프레임 간격·부분 정밀 재분석으로 자원을 사용한다. UI 응답성과 메모리 안전을 위해 무제한 코어/GPU 점유를 시도하지 않는다. 촬영 영상은 앱에서 명시적으로 저장하기 전 메모리 Blob으로 분석하고 저장 시 결과와 원본을 IndexedDB에 보존한다. 운영체제 스왑/브라우저 임시 저장까지 제어하지 않는다.

합성 좌표 및 DOM 테스트 45개 통과, 실제 WebM/샘플 도구가 필요한 2개 건너뜀. 실촬영 정확도와 임상적 점수 검증은 별도 수행이 필요하다. 실제 카메라에서 각 동작 촬영→자동 종료→결과→관절 수정→재계산→저장/불러오기를 확인하는 것이 다음 수용검사다.
